# Криптобот: DCA на Bybit (спот BTC/USDT)

Простой и осторожный бот: регулярно покупает биткоин на фиксированную сумму (DCA),
дополнительно докупает на просадках и (по желанию) частично фиксирует прибыль.
**Только спот, без плеча и фьючерсов.** Реальные деньги по умолчанию выключены.

> Никакой бот не гарантирует прибыль. Бэктест показывает прошлое, а не будущее.

## Установка
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Режимы
| Команда | Что делает |
|---|---|
| `python bot.py fetch` | Скачивает историю свечей 1d и 4h за ~2 года в `data/` (Bybit, если недоступен — публичный архив Binance) |
| `python bot.py backtest --tf 1d` | Бэктест: обычный DCA, DCA + просадки, DCA + просадки + фиксация прибыли, «купить и держать». Таблица в консоли и `results/`, график `backtest.png` |
| `python bot.py testnet --once` | Один шаг на **тестовой** бирже Bybit (ненастоящие деньги) |
| `python bot.py testnet --loop` | Работает постоянно, проверяет рынок раз в час |
| `python bot.py live --once --i-understand-real-money` | Реальные деньги. Работает, только если в `config.yaml` стоит `live_enabled: true` **и** указан флаг |

## Как работает стратегия
1. **Регулярная покупка** раз в `interval_days` дней (по умолчанию раз в неделю).
   Сумма = бюджет × `base_share` / число периодов (1000 × 0.7 / 104 ≈ 6.73 USDT в неделю).
   Если докупки на просадках выключены — весь бюджет идёт на регулярные покупки (≈ 9.62 USDT).
2. **Докупки на просадках**: если цена упала на 5% / 10% / 20% от максимума за 30 дней —
   докупаем 15 / 25 / 40 USDT. Каждый уровень срабатывает один раз, пока цена не восстановится.
   Докупки тратят только резерв (30% бюджета), регулярные покупки он не съедает.
3. **Фиксация прибыли** (выключена): если цена выше средней цены входа на 50% — продаём 20% BTC.

## Жёсткие ограничения (config.yaml → `limits`)
- `max_total_budget_usdt` — больше этой суммы бот не потратит никогда.
- `max_order_usdt` — максимум на один ордер.
- `min_order_usdt` — меньшие ордера не отправляются.
- Бот откажется запускаться, если `category` не `spot` или пара не BTCUSDT. Все ордера — `isLeverage=0`.

## Тестовая биржа (testnet)
1. Зарегистрируйтесь на https://testnet.bybit.com (отдельный аккаунт, не основной).
2. Возьмите тестовые USDT (в разделе Assets есть кнопка запроса тестовых средств).
3. API Management → Create New Key → System-generated, права **только Spot Trade** (Read-Write), без вывода.
4. Задайте ключи и запустите:
```bash
export BYBIT_API_KEY=ваш_ключ
export BYBIT_API_SECRET=ваш_секрет
python bot.py testnet --once
```
Состояние (сколько потрачено, сколько BTC) хранится в `testnet_state.json`.
Без ключей бот просто напишет, где их взять, и ничего не сделает.

Важно: Bybit блокирует доступ из некоторых стран (в том числе США). Запускайте бота
с компьютера, откуда сайт Bybit у вас открывается.

## Файлы
- `bot.py` — запуск и режимы, работа с биржей (pybit)
- `strategy.py` — логика DCA (одна и та же для бэктеста и торговли)
- `backtest.py` — симуляция и график
- `fetch_data.py` — загрузка истории
- `config.yaml` — все настройки
- `data/` — свечи, `results/` — таблицы бэктеста
